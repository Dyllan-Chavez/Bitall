# Bitall
# BITALL 🛍️  Plataforma web de comercio local que conecta compradores con pequeños negocios y vendedores ambulantes mediante geolocalización, facilitando el descubrimiento de productos cercanos, la consulta de comercios y la gestión de pedidos. Su objetivo es impulsar el comercio local a través de una herramienta digital accesible, intuitiva y fácil de utilizar.
